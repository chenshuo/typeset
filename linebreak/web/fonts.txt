# Fonts for the page when web/build.sh is given no font files.  The page
# downloads each from its URL when the user picks it, and checks its SHA-256.
# One per line: URL SHA256 [NAME].  NAME is the name in the list, by default
# the Chinese name in the font.  The list is in this order; the default is
# the smallest file, the quickest to download.  Each font file must hold a single face, not a TTC.
#
# The URLs are jsDelivr, which allows cross-origin requests and caches for a
# year, at a commit rather than a tag, as a tag may move.  jsDelivr serves
# files in GitHub repositories up to 20 MB, not release assets.
